## OpenRouter
- [Sign up for OpenRouter](https://openrouter.ai/)
- [Connect your Cerebras API key (Settings → Integrations)](https://openrouter.ai/settings/integrations)
- [Redeem hackathon coupon code](https://openrouter.ai/redeem) - Use code `OPENROUTER-CEREBRAS-HACKATHON` for $5 in credits (valid until October 4)
- How it works: OpenRouter routes requests to providers based on model, latency, and price.
- Token usage with Cerebras: If your Cerebras key is connected, OpenRouter uses available Cerebras free tokens first; after those are exhausted, OpenRouter credits are used. You can also continue calling the Cerebras API directly.
