# Testimonials Images

## Mike Piccolo Image

Please add Mike Piccolo's image file to this directory.

**File name options:**
- `mike-piccolo.jpg`
- `mike-piccolo.webp`
- `mike-piccolo.png`

**Steps:**
1. Add the image file to this directory
2. Update `index.ts` to import the image with the correct filename
3. Remove the placeholder export

Example:
```typescript
import mikePiccolo from "./mike-piccolo.jpg";
export { mikePiccolo };
```
