mission-brief.sql · SigNoz Query Builder
-- P99 latency by operation for an AI agent
SELECT
  serviceName,
  name AS operation,
  quantile(0.99)(durationNano) / 1e6 AS p99_ms,
  count() AS total_spans
FROM signoz_traces.distributed_signoz_index_v3
WHERE serviceName = 'agent-orchestrator'
  AND timestamp > now() - INTERVAL 1 HOUR
GROUP BY serviceName, name
ORDER BY p99_ms DESC LIMIT 10;

See Inside Everything You Ship

AI is eating software, and nobody can see inside it. Your mission in this hackathon is to build agent-native observability workflows, SRE copilots, and AI/LLM observability dashboards powered by SigNoz and OpenTelemetry.

AI agents are chaining LLM calls, invoking tools, hitting vector DBs, and making decisions autonomously. But when latency spikes, costs explode, or an agent hallucinates in production, you're flying blind.

SigNoz gives you full visibility into every AI workflow. Trace each agent step, monitor token costs, and correlate LLM responses with downstream failures. OpenTelemetry-native, so your instrumentation works everywhere.

One platform. Every AI signal. Total observability. 🔍
