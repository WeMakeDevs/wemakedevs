# Resources

To help you get started with contributing to Kestra, we've compiled essential resources. Make sure to explore these before and during the event!

## Kestra Community
- [Join Kestra Slack](https://kestra.io/slack) - Main community hub for contributors
- Use the #contributors channel for questions and help
- Use the #introductions channel to introduce yourself

## Getting Started
- [Kestra Getting Started Guide](https://kestra.io/docs/getting-started) - Learn the basics of Kestra
- [How-to Guides](https://kestra.io/docs/how-to-guides) - Step-by-step tutorials for common tasks
- [Tutorial Videos](https://kestra.io/tutorial-videos/all) - Video tutorials for visual learners
- [Kestra Blueprints](https://kestra.io/blueprints) - Pre-built workflows and examples

## Contributing to Kestra
- [Contributing Guide](https://kestra.io/docs/getting-started/contributing) - Complete guide on how to contribute
- [GitHub Repository](https://github.com/kestra-io/kestra) - Main Kestra repository
- [Issue Tracker](https://github.com/kestra-io/kestra/issues) - Find issues to work on
