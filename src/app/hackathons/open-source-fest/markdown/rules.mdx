# Open Source Fest Rules

## 1. Join the Slack

Join the [Kestra Slack community](https://kestra.io/slack) and head to the #contributors channel to ask questions or get help. Please use the right channels for the right purpose. Don't spam or send introductions anywhere except the #introductions channel. Keep things clean and helpful for everyone.

---

## 2. Asking Good Questions

Before asking, take a minute to:
- Search the docs, issues, or Slack history to see if it's already answered.
- Be specific: include what you tried, what didn't work, and where you got stuck.
- Share relevant links or code snippets (never full logs or screenshots unless necessary).

Good questions show effort and you'll get faster, better responses from the community.

---

## 3. Getting Assigned to an Issue

- Always check if the issue is already assigned.
- If it's assigned, you can comment politely asking if help is needed.
- If not, comment on the issue explaining how you plan to solve it, and tag MartinRst to request assignment.
- Wait until it's assigned to you before starting any work.

---

## 4. Pull Requests (PRs)

- Do not open PRs unless you've been assigned to the related issue.
- Every PR must be linked to an existing issue.
- Any PR without an assigned issue will result in a permanent ban from all WeMakeDevs events, no exceptions.

---

## 5. Opening New Issues

You're encouraged to open issues if you find bugs or have ideas, but keep them meaningful. Small improvements are welcome, but:
- Don't open issues just for participation.
- Don't submit spam or low-effort issues.

Fake or irrelevant issues will lead to a permanent ban from all WeMakeDevs events, no exceptions.

---

## Code of Conduct

We're a community that values respect, collaboration, and inclusion. Be kind, be patient, and remember that everyone is learning. Harassment, discrimination, or disrespectful behavior of any kind will not be tolerated. If you see something that goes against these values, report it to the moderators immediately at [contact@wemakedevs.org](mailto:contact@wemakedevs.org).
